# How to work from now on

One workspace, two ways in. Both read the same files, the same skills and the same connectors.

## Option A: Claude Code in VS Code (recommended for daily work)
1. Install VS Code and the Claude Code extension. Sign in with the same claude.ai account that has Slack, Canva, Brevo, Gmail and Savee connected.
2. Clone this repo and open the folder.
3. Claude loads `CLAUDE.md` and the skills in `.claude/skills/` on its own. Nothing to paste.
4. When you finish something, ask Claude to "commit and push" so the next session sees it.

## Option B: Cowork (desktop app)
1. In Cowork, create a project called **Regulars HQ** and point it at this folder.
2. If the project does not pick up `CLAUDE.md` by itself, paste its text into the project instructions.
3. Set the scheduled tasks below.

## Scheduled tasks (set once in Cowork)
1. **Monday 08:47, Regulars weekly kickoff:** "Run step 1 of regulars-marketing-agent. Read #gtm-csm and #gtm-marketing from the last 7 days, update regulars/TASKS.md and the HQ page, and propose the week's plan."
2. **Friday 13:52, Regulars weekly review:** "Run step 5 of regulars-marketing-agent. Ask me for the numbers, compare with 05-results.md and propose two changes."
3. **First Monday of the month 10:13, Regulars monthly:** "Run marketing:competitive-brief and marketing:performance-report. Update 04-competitors.md and 05-results.md."

## First test (run these once after setup)
If the answers feel generic, the file paths in CLAUDE.md need to be more explicit.
1. "Using the Regulars Brain, tell me the three biggest missed opportunities in my current work."
2. "Read my priorities and tasks. What is likely to fall through the cracks this week?"
3. "Look at my files and tell me what I'm overcomplicating."

## Keep it alive
1. Monday: update PRIORITIES.md (Claude proposes, you approve).
2. When Alex or HC decides something: "Add this to the decisions log: [decision]".
3. When something is published: "Move [piece] to archive".
4. When a draft misses your standard: "Update the writing voice skill with this example".
5. Don't add everything at once. Add a file only when you catch yourself explaining it to Claude twice.

## Thinking partner
1. "I'm thinking through [problem]. Don't write anything yet. Ask me the questions that would help me think it through, using what you know about Regulars and Alex."
2. "I have 90 minutes. What's the highest leverage thing I could work on?"

## Prompts that work
1. "What's on today?"
2. "Make the welcome post for [venue]."
3. "Write pinned post [Why / How] with Alex's caption as the base. Give me three hooks and tell me which one Alex would pick and why."
4. "Turn this idea into a LinkedIn post for [owners / group CEOs]: [idea]. Add the 5W1H for the Slack thread."
5. "Prepare the newsletter for [date] from 08-newsletter-plan.md as a Brevo draft."
6. "Find [5] venues in [city] that fit Regulars and write the first email and two follow ups, each with a new angle."
7. "Review this as Alex would: [text]."
8. "Here are this week's numbers: [paste]."
